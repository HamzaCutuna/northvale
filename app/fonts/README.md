# Northvale font assets

Downloaded on 2026-09-10 from the official Google Fonts service. These are the unmodified Latin-subset WOFF2 files provided by the CSS API for a modern browser.

Stylesheet source:
https://fonts.googleapis.com/css2?family=Cormorant+Garamond:ital,wght@0,400;1,400&family=Manrope:wght@400..600&display=swap

| File | Family | Style | CSS weight |
| --- | --- | --- | --- |
| `cormorant-garamond-latin-400-normal.woff2` | Cormorant Garamond | normal | 400 |
| `cormorant-garamond-latin-400-italic.woff2` | Cormorant Garamond | italic | 400 |
| `manrope-latin-variable.woff2` | Manrope | normal | 400 600 |

The Manrope resource is the variable font served for the requested 400–600 weight range; configure that range when loading it. Cormorant files were requested at weight 400 only.
